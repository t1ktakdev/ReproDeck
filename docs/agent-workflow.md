# ReproDeck Agent Workflow

This project uses OpenSpec + independent OpenCode agents.

## Normal daily command
/repro-continue

The Builder must run the quality gate, request independent review, fix BLOCKER/HIGH findings, rerun the gate, and re-review before claiming a checkpoint is complete.

## Independent checks
- /repro-review — read-only adversarial code review
- /repro-security — read-only security review
- /repro-gate — deterministic quality gate
- /repro-research <question> — primary-source technical research
- /repro-ux — UI/UX review when frontend work starts

## OpenSpec
OpenCode integration generated by OpenSpec uses commands such as:
- /opsx-explore
- /opsx-propose
- /opsx-apply
- /opsx-archive

Use OpenSpec for significant NEW features/architecture changes. Existing audit fixes can finish their current checkpoint first.

## Independent ZIP audit

powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/make-review-zip.ps1
